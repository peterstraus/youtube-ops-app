Privacy Policy — YouTube Ops Daily Report

Last updated: 2026-10-25

What the app accesses

With the channel owner's consent, the app uses read-only access (yt-analytics.readonly, youtube.readonly) to read analytics and statistics of the owner's own YouTube channels.

How data is used and stored

The data is used only to build a daily summary for the channel owner. It is stored only on the owner's own computer and sent only to the owner's private Discord channel. It is not sold, shared with third parties, or used for advertising.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored data can be deleted by the owner at any time.
